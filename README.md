# MexCity RP - Sistema de Roleplay Completo

## 🎮 Descripción
Plataforma de roleplay para jugadores en vivo con sistema bancario, empresas, empleos, chats y gestión de personajes.

## 📁 Estructura de Archivos

```
/
├── index.html              # Landing page
├── dashboard.html          # Dashboard principal
├── config.js              # Configuración
├── auth.js                # Autenticación
├── player-manager.js      # Gestión de jugadores
├── schema.sql             # Base de datos
└── logo.png
```

## 🎯 Funcionalidades

✅ Registro progresivo de personajes
✅ Sistema bancario integrado
✅ Empresas y empleos
✅ Chats en tiempo real
✅ Responsive design

## 📱 Dispositivos Soportados

- Mobile (360px+)
- Tablet (768px+)
- Desktop (1024px+)
